מערכת לניהול מערך תחבורה ציבורית – #SQL Server
אודות ##הפרויקט
פרויקט זה מציג תשתית נתונים מלאה לניהול חברת תחבורה. המערכת מאפשרת ניהול לוגיסטי חכם של קווי נסיעה, תחנות, ערים ושיבוץ עובדים, תוך שמירה על שלמות הנתונים ואוטומציה של תהליכים עסקיים.

יכולות טכניות שהוטמעו##:
בפרויקט זה באים לידי ביטוי כלים מתקדמים ב-SQL:

תכנון מסד נתונים רלציוני: בניית סכמה חכמה עם קשרי גומלין (Foreign Keys) ומגבלות (Constraints).

פרוצדורות (Stored Procedures): לוגיקה מורכבת להוספת עובדים כולל בדיקות תקינות (Validation) וניהול טרנזקציות.

פונקציות (Functions): חישוב נתונים דינמיים כמו כמות נסיעות חודשית לנהג.

טריגרים (Triggers): הקמת מנגנון Audit (תיעוד) אוטומטי העוקב אחרי שינויים בטבלאות התשתית.

ניהול טרנזקציות: הבטחת אמינות הנתונים בתהליכי מחיקה ועדכון מורכבים (Rollback/Commit).

פיצ'רים מרכזיים##
בדיקת תקינות זהות: מנגנון המוודא תקינות תעודות זהות לפני הזנה למערכת.

דוחות וסטטיסטיקה: שאילתות מתקדמות המציגות נתוני נסיעות ושיבוצים בזמן אמת.

לוג בקרה: מעקב מלא אחרי מחיקות ועדכונים בטבלת התחנות.
